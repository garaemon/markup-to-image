# Markup to Image

Convert Markdown, LaTeX, and Mermaid diagrams into beautiful images.

Live Demo: [https://m2i.garaemon.com](https://m2i.garaemon.com)

## Features

- **Markdown Support**: Render rich text with GFM support.
- **LaTeX Support**: Professional math equations using KaTeX.
- **Mermaid Diagrams**: Create flowcharts, sequence diagrams, and more.
- **Image Export**: Export your markups as high-quality images.
- **Shareable URLs**: Save your state in the URL and share it with others.

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
